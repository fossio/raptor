# raptor

Biblioteca Rust multi-crate para parsing do protocolo OFX (SGML 1.x + XML 2.x), com analytics financeiro e alvo WASM — processa extrato/fatura bancário inteiramente no navegador, sem upload para servidor.

Decisões de arquitetura completas: [`docs/discovery-ofx-rust-wasm.md`](docs/discovery-ofx-rust-wasm.md). Roadmap: [`docs/roadmap-github.md`](docs/roadmap-github.md). Contexto de UX/produto: [`docs/handoff-ux-design-frontend.md`](docs/handoff-ux-design-frontend.md).

Índice completo da documentação, incluindo o histórico de auditoria que as issues referenciam por número: [`docs/README.md`](docs/README.md).
